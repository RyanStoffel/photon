# Security policy

## Supported versions

Only the latest tagged release of Photon is supported with security fixes.

## Reporting a vulnerability

Please do **not** open a public issue for a security vulnerability.

Email Ryan Stoffel at [stoffel.thomas.ryan@gmail.com](mailto:stoffel.thomas.ryan@gmail.com) with:

- A description of the issue and its impact
- Steps to reproduce, or a proof of concept
- The Photon version (or commit) you tested

You should receive an acknowledgement within a few days. Please allow time to investigate and ship a fix before any public disclosure.

## Scope

Photon is a local macOS app. Reports that involve local privilege escalation, unexpected access to clipboard or notes data, or a way to run untrusted code via the launcher are in scope. Issues that require physical access and a unlocked session are lower priority.
